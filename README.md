# DonePDF

**Free online PDF tools: edit, convert, compress, sign and organize PDFs. No sign-up, no watermarks.**

🌐 **Website:** [donepdf.com](https://donepdf.com)

DonePDF is a free PDF toolkit with 90+ tools in 20 languages. Most tools run directly in the browser, so files stay on the user's device. It is built for students, office workers, freelancers and small businesses who need to fix a PDF quickly without installing software or paying for a subscription.

## ✨ Highlights

- 🔒 **Private by design:** most tools process files locally in the browser
- 🚫 **No account, no watermark, no daily limits**
- 🌍 **20 languages**, with full support for Arabic and other right-to-left languages
- ✏️ **A real online editor:** change the existing text of a PDF in place, and turn scanned pages into editable text with OCR

## 🛠️ How it works

DonePDF uses open web technologies to work with PDF files inside the browser:

- **[pdf.js](https://github.com/mozilla/pdf.js)** to read and render pages
- **[pdf-lib](https://github.com/Hopding/pdf-lib)** to write changes back into the PDF as real PDF content
- **[Fabric.js](https://github.com/fabricjs/fabric.js)** for the interactive editing canvas
- **[Tesseract.js](https://github.com/naptha/tesseract.js)** for text recognition (OCR) on scanned pages

A few tools that need heavier processing run on the server; their pages say so.
